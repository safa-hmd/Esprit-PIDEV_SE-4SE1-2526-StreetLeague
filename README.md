## Description

StreetLeague is a unified web platform for amateur sports communities. It integrates team management, tournaments, field reservations, health tracking, a sports marketplace, and community features in a single application.

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Angular, TypeScript, Bootstrap |
| Backend | Spring Boot, Java, JPA/Hibernate |
| Database | MySQL |
| Auth | Spring Security, JWT, BCrypt |
| DevOps | Docker, Jenkins, Kubernetes |
| Monitoring | Prometheus, Grafana |

---

## Installation

```bash
# Clone the repository
git clone https://github.com/safa-hmd/Esprit-PIDEV_SE-4SE1-2526-StreetLeague.git

# Backend
cd backend
mvn spring-boot:run

# Frontend
cd frontend
npm install
ng serve
```
